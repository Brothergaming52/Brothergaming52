## 🚀 Featured Projects

### 🎒 [CuriosPaper](https://github.com/Brothergaming52/CuriosPaper)
![Stars](https://img.shields.io/github/stars/Brothergaming52/CuriosPaper?style=flat&color=yellow) ![Release](https://img.shields.io/github/v/release/Brothergaming52/CuriosPaper?style=flat&color=blue) ![Last Commit](https://img.shields.io/github/last-commit/Brothergaming52/CuriosPaper?style=flat)

The Ultimate Custom Accessory Inventory System for Paper & Spigot — think *Baubles/Curios*, but fully server-side with no client mods required. 9 accessory slots, an ability system, 3D equipped models, in-game GUI editors (items, recipes, loot tables, mob drops, trades), and a full developer API with custom events.

`Java` · [📖 Docs](http://www.curiospaper.run.place/) · [💬 Discord](https://discord.gg/r5YXqgrGya) · [☕ Ko-fi](https://ko-fi.com/brothergaming52)

### ⚔️ [PaperArtifacts](https://github.com/Brothergaming52/PaperArtifacts)
![Stars](https://img.shields.io/github/stars/Brothergaming52/PaperArtifacts?style=flat&color=yellow) ![Last Commit](https://img.shields.io/github/last-commit/Brothergaming52/PaperArtifacts?style=flat)

A content addon for CuriosPaper — an unofficial server-side port of the *Artifacts* mod. Adds 45+ magical accessories, underground abandoned campsites, and mimic enemies disguised as loot chests.

`Java` · Addon for CuriosPaper

### 🕸️ [SSMP Enemy Syncing Addon](https://github.com/Brothergaming52/ssmp-enemy-sync)
![Stars](https://img.shields.io/github/stars/Brothergaming52/ssmp-enemy-sync?style=flat&color=yellow) ![Last Commit](https://img.shields.io/github/last-commit/Brothergaming52/ssmp-enemy-sync?style=flat) ![License](https://img.shields.io/github/license/Brothergaming52/ssmp-enemy-sync?style=flat)

Real-time enemy & boss synchronization addon for **Hollow Knight: Silksong Multiplayer (SSMP)**. Syncs FSMs and multi-phase boss fights, uses proximity-based AI authority claiming, and adds a co-op "downed & cocoon" revive system.

`C#` · Built for [SSMP](https://github.com/Extremelyd1/SSMP)
